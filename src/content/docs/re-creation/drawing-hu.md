# 插画@呼葱觅蒜

无脸人像画，神韵极佳。《梦华录》实体书附增部分插画。

所谓伊人，在水一方
![](/image/erchuang/piant/hu/22-min.webp)

盈盈一水间，脉脉不得语
![](/image/erchuang/piant/hu/18-min.webp)

念去去，千里烟波，暮霭沉沉楚天阔
![](/image/erchuang/piant/hu/2-min.webp)

天街小雨润如酥，草色遥看近却无
![](/image/erchuang/piant/hu/12-min.webp)

若非群玉山头见，会向瑶台月下逢
![](/image/erchuang/piant/hu/3-min.webp)

醉后不知天在水，满船清梦压星河
![](/image/erchuang/piant/hu/15-min.webp)

柔情似水，佳期如梦
![](/image/erchuang/piant/hu/11-min.webp)

月上柳梢头，人约黄昏后
![](/image/erchuang/piant/hu/14-min.webp)

只愿君心似我心
![](/image/erchuang/piant/hu/13-min.webp)

帐里鸾凤喜合双，围红倚翠烂芬芳
![](/image/erchuang/piant/hu/17-min.webp)

美人如玉剑如虹

![](/image/erchuang/piant/hu/9-min.webp)

起舞弄清影，何似在人间
![](/image/erchuang/piant/hu/8-min.webp)

事了拂衣去，深藏身与名
![](/image/erchuang/piant/hu/10-min.webp)

飘飘乎如遗世独立，羽化而登仙
![](/image/erchuang/piant/hu/5-min.webp)
